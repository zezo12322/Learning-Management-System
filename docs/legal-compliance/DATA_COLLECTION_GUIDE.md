# Data Collection Guide for OptimaTech LMS

**Purpose:** This guide outlines all data points that can be collected from users, categorized by legal compliance requirements for Egypt and international standards.

**Note:** This document is for internal team use only. Final legal review and approval must be obtained from your legal team before implementing any data collection practices.

---

## 1. DATA THAT CAN BE COLLECTED (With User Consent)

### 1.1 Identity Information (Mandatory for registration)

| Data Field        | Description           | Legal Basis                    | Collection Method              |
| ----------------- | --------------------- | ------------------------------ | ------------------------------ |
| **Name**          | Full name of the user | Contract (to provide service)  | User input during registration |
| **Email Address** | User's email          | Contract + Legitimate interest | User input during registration |
| **Phone Number**  | User's phone          | Legitimate interest (optional) | Optional user input            |
| **User ID (UID)** | Firebase Auth UID     | Contract                       | Auto-generated by Firebase     |

### 1.2 Profile Information (Optional)

| Data Field                 | Description                 | Legal Basis              | Collection Method           |
| -------------------------- | --------------------------- | ------------------------ | --------------------------- |
| **Avatar/Profile Picture** | User profile photo          | Consent                  | User upload                 |
| **Bio**                    | User biography/summary      | Consent                  | Optional user input         |
| **Company**                | User's employer/company     | Consent                  | Optional user input         |
| **National ID**            | Government-issued ID number | Legal obligation (Egypt) | Optional upload (ENCRYPTED) |

| Data Field                 | Description                           | Legal Basis | Collection Method            |
| -------------------------- | ------------------------------------- | ----------- | ---------------------------- |

## 2. DATA THAT CANNOT BE COLLECTED (Without Explicit Permission)

### 2.1 Sensitive Personal Data (PROHIBITED without explicit consent)

| Data Type                              | Risk Level | Why Not                     | Exception                                        |
| -------------------------------------- | ---------- | --------------------------- | ------------------------------------------------ |
| **Biometric Data** (face, fingerprint) | HIGH       | Requires explicit consent   | May be allowed for security with lawyer approval |
| **Health/Medical Data**                | HIGH       | Requires explicit consent   | Never collect unless medical course              |
| **Financial Data** (full card numbers) | HIGH       | PCI-DSS compliance required | Never store, use Paymob tokens only              |
| **Religious Beliefs**                  | HIGH       | Privacy intrusion           | Never collect                                    |
| **Political Opinions**                 | HIGH       | Privacy intrusion           | Never collect                                    |
| **Genetic Data**                       | HIGH       | Privacy intrusion           | Never collect                                    |

### 2.2 Data Requiring Special Handling

| Data Type                    | Current Status | Requirements                              |
| ---------------------------- | -------------- | ----------------------------------------- |
| **Location (Precise GPS)**   | Not collected  | Requires explicit consent + justification |
| **Contact List**             | Not collected  | Requires explicit consent                 |
| **Calendar Data**            | Not collected  | Requires explicit consent                 |
| **Microphone/Camera Access** | Not collected  | Requires explicit consent + purpose       |

## 3. WHAT MUST BE IN THE PRIVACY POLICY

### 3.1 Mandatory Sections (Egyptian Data Protection Law + GDPR)

#### Section 1: Information We Collect

- List all data categories collected (from Section 1 above)
- Explain how data is collected (user input, automatic tracking)
- Mention third-party services (Firebase, Paymob, etc.)

#### Section 2: How We Use Your Information

- Provide courses and educational content
- Process payments and issue certificates
- Track progress and generate reports
- Improve service quality
- Communicate with users
- Prevent fraud and security threats
- Comply with legal obligations

#### Section 3: Legal Basis for Processing

- **Contract:** Necessary to provide the service
- **Consent:** User has explicitly agreed
- **Legal Obligation:** Required by Egyptian law
- **Legitimate Interest:** Security, fraud prevention

#### Section 4: Data Sharing and Disclosure

- Service providers (Firebase, Paymob, etc.)
- Legal requirements (court orders, government requests)
- Business transfers (mergers, acquisitions)
- **DO NOT sell user data**

#### Section 5: Data Transfers

- Data may be stored internationally
- Safeguards in place (encryption, SCCs)
- User's right to information about transfers

#### Section 6: Data Retention

- Account data: Until user requests deletion
- Payment records: 7 years (tax compliance)
- Audit logs: 90 days (GDPR data minimization)

#### Section 7: User Rights (GDPR & Egyptian Law)

- **Access:** Request copy of personal data
- **Correction:** Request data correction
- **Deletion:** Request data deletion ("Right to be Forgotten")
- **Restriction:** Request restriction of processing
- **Portability:** Receive data in structured format
- **Objection:** Object to processing
- **Withdraw Consent:** Withdraw consent at any time

#### Section 8: Data Security

- Encryption in transit (TLS 1.3)
- Encryption at rest (database)
- Access controls
- Regular security assessments

#### Section 9: Children's Privacy

- Not for users under 13
- No knowingly collecting children's data

#### Section 10: Changes to Privacy Policy

- How updates will be communicated
- Date of last update

#### Section 11: Contact Information

- Data Protection Officer email
- Contact details
- Regulatory authority (Egyptian Data Protection Authority)

## 4. THIRD-PARTY SERVICES & DATA SHARING

### 4.1 Firebase (Google)

- **Purpose:** Authentication, Database, Storage
- **Data Collected:** User ID, email, name, avatar, data stored in Firestore/Data Connect
- **Privacy Policy:** https://firebase.google.com/support/privacy
- **Transfer:** Data may be processed in US/EU servers

### 4.2 Paymob (Payment Processor)

- **Purpose:** Payment processing
- **Data Collected:** Email snapshot, payment amount, reference ID, gateway information
- **Privacy Policy:** https://paymob.com/privacy-policy
- **Transfer:** Payment data processed by Paymob

### 4.3 Video Streaming Services

- **Purpose:** Video content delivery
- **Data Collected:** User session, watch history
- **Privacy Policy:** Varies by provider
